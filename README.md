# Marketing campaign performance analysis

This project looks at customer data to see how marketing campaigns performed, how customers spend, and which groups respond best.

Built with SQL, Python and Tableau.
## Project overview

The dataset covers 2,241 customers: their demographics, spending by product, purchase channels, and how they responded to several marketing campaigns.

I wanted to find out what makes a campaign work and give the marketing team some clear next steps.

## Insights

- High Spenders respond to campaigns at more than double the rate of Low Spenders (21% against 9%).
- Customers aged 18 to 30 respond most often, at 18.2%.
- Wine is by far the top product category by total spending.
- The most recent campaign did best, with a 14.9% response rate.
- Campaign 2 did very poorly, at only 1.3%.
- Store and Web are the main purchase channels.

## Recommendations

- Put more of the campaign effort into High Spenders and younger customers.
- Run special promotions around wine.
- Find out what made the latest campaign work and reuse it.
- Don't repeat the approach behind Campaign 2.
- Improve the website and in-store experience so campaigns convert better.
